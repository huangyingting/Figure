# Figure

Figure is a visual learning app that turns a topic into an AI-generated image with a separate, editable spatial annotation layer. Generated figures are saved automatically, can be published or collected, and become component-level recall quizzes.

## Product surfaces

- `/studio` — plan, render, spatially ground, review, and export a figure.
- `/discover` — browse and search public figures.
- `/library` — search and sort everything generated by the signed-in user.
- `/collections` — create color-coded collections and save public or owned figures.
- `/quiz` — take component recall quizzes; attempts and mastery are persisted.
- `/credits` — inspect the current balance and immutable generation ledger.
- `/signin` and `/register` — local email/password authentication plus optional Google and Facebook OAuth.

All menu-style selects use the shared accessible custom listbox component; the application does not render browser-native `<select>` controls.

## Local setup

```bash
npm install
cp .env.example .env.local
npm run db:generate
npm run db:push
npm run db:seed
npm run dev
```

The seed adds a public centrifugal-pump lesson and the local development account `demo@figure.local` / `figure-demo`. Seed credentials are for local development only.

Run the full verification gate with:

```bash
npm run check
```

## Authentication

The app uses Auth.js/NextAuth v5 with JWT sessions. Credentials authentication works locally; OAuth providers are registered only when both credentials are present.

```dotenv
AUTH_SECRET=replace-with-a-random-secret-at-least-32-characters
AUTH_URL=http://localhost:3000

AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=
AUTH_FACEBOOK_ID=
AUTH_FACEBOOK_SECRET=
```

Development callback URLs are:

- Google: `http://localhost:3000/api/auth/callback/google`
- Facebook: `http://localhost:3000/api/auth/callback/facebook`

New local accounts receive 12 credits. A successful generation consumes one credit atomically; pipeline failures create an idempotent refund entry.

## Persistence and image storage

Prisma owns relational data for users, provider accounts, figures, collections, quiz attempts, and credit-ledger entries. SQLite is the local default:

```dotenv
DATABASE_URL=file:./dev.db
```

Large image bytes stay outside the database behind a content-addressed storage interface modeled after the neighboring `ReadWise` application. The relational figure row stores only the private object key and metadata.

Local filesystem storage is the default:

```dotenv
FIGURE_STORAGE=local
FIGURE_STORAGE_DIR=./.media
```

Azure Blob Storage is enabled with:

```dotenv
FIGURE_STORAGE=azure
AZURE_STORAGE_CONNECTION_STRING=
# Or AZURE_STORAGE_ACCOUNT plus AZURE_STORAGE_KEY
AZURE_STORAGE_CONTAINER=figures
```

Stored images are served through an authorization-aware application route. Private objects are visible only to their owner; public figures can be browsed by anyone.

## Azure AI configuration

The server supports `gpt-image-2` and `MAI-Image-2.5` image deployments plus a vision-capable deployment for planning and spatial grounding. Browser clients never receive provider credentials.

See `.env.example` for the complete set of Azure OpenAI, Microsoft Foundry, timeout, image-quality, authentication, database, and object-storage variables.

The generated image is intentionally label-free. The vision pass returns normalized anchors and boxes independently, keeping visual pixels, annotation copy, review status, and quiz content editable and auditable.
